🔧 Car Servicing Log

Keep a record of what was done to the car, and when — stored in your own Google Sheet.

First time? Set up Google access (once, ~3 minutes)
  1. Open the Google Cloud console and create a project (any name).
  2. In APIs & Services → Library, enable the Google Sheets API.
  3. In APIs & Services → OAuth consent screen, pick External, fill in the required names, and add your own Google address under Test users.
  4. In Credentials → Create credentials → OAuth client ID, choose Web application and add https://michael.mcand.ru as an authorised JavaScript origin (add http://localhost:8000 too if you run this page locally).
  5. Copy the client ID that ends in .apps.googleusercontent.com and paste it above.

The client ID and sheet are remembered in this browser's local storage. Nothing is sent anywhere except Google — this page is static and has no server. Because the app is unverified, Google shows a "Google hasn't verified this app" warning the first time; continue past it as the test user you added.
